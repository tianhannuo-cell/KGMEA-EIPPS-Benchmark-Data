This repository provides benchmark inputs for the study “Knowledge-guided multi-objective evolutionary algorithm for energy-efficient integrated process planning and scheduling with speed scaling”.

It contains 18 job data files, 24 problem definitions, machine energy parameters for 15 machines, and three processing-speed levels. The problem definitions combine the job files into instances containing 6, 9, 12, 15, or 18 jobs.

The job data are stored in the jobs directory. The file problems.txt lists the job combinations for the 24 instances. The energy directory contains the base processing power, idle power, switching energy, and the time and power factors associated with each speed level.
